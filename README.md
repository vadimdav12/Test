## Запуск тестов

```bash
# Все тесты
pytest

# Только блочные
pytest tests/unit/

# Только интеграционные
pytest tests/integration/

# Только приёмочные
pytest tests/acceptance/

# Только нагрузочные
pytest tests/load/

# Конкретный модуль
pytest tests/unit/test_cart_service.py

# С покрытием кода
pytest --cov=app --cov-report=html
```

## Описание тестовых сценариев

### Блочные тесты (Unit)

Проверяют отдельные компоненты системы в изоляции:

- **CatalogService**: получение категорий, товаров, CRUD операции
- **CartService**: добавление, обновление, удаление, расчёт итогов
- **OrderService**: создание заказов, изменение статусов, отмена
- **DiscountService**: валидация промокодов, расчёт скидок
- **SearchService**: нечёткий поиск, транслитерация
- **FavoritesService**: избранное пользователя
- **ProfileService**: профиль и история заказов
- **ReceiptService**: генерация PDF-чеков
- **NotificationService**: уведомления пользователям и админам

### Интеграционные тесты

Проверяют взаимодействие компонентов:

- И01: Навигация по каталогу
- И02: Отображение товаров категории
- И03-И04: Операции с корзиной
- И05-И06: Оформление заказа через FSM
- И07-И08: Платёжная интеграция
- И09: Поиск на русском языке
- И10: Избранное
- И11: Промокоды
- И12: Админ-панель

### Приёмочные тесты

Проверяют пользовательские сценарии end-to-end:

- А01: Полный путь нового покупателя
- А02: Поиск и покупка
- А03: Покупка с промокодом
- А04-А06: Постоянный покупатель
- А07-А10: Граничные случаи
- А11-А12: Сценарии администратора

### Нагрузочные тесты

Проверяют производительность:

- Н01-Н02: Нагрузка на каталог (100 RPS)
- Н03-Н04: Нагрузка на корзину
- Н05-Н06: Нагрузка на поиск
- Н07-Н08: Нагрузка на скидки
- Н09: Создание заказов
- Н10: Смешанная нагрузка
